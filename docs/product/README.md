# Documentação de Produto

Este diretório conterá:

- visão do produto;
- usuários e personas;
- jornadas;
- regras de negócio;
- módulos;
- roadmap funcional;
- backlog de produto.

O documento de produto no Google Drive permanece como referência funcional atual até que seu conteúdo seja migrado e versionado neste repositório.

A documentação de produto deve ser escrita em português do Brasil.
