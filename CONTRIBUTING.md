# Contributing

Thank you for your interest in the project.

## Current contribution policy

The repository is currently in **Phase 0 — Engineering Foundation**. External code contributions are not actively solicited yet while the core architecture, governance and unattended development runtime are being finalized.

Issues, architectural feedback and review observations are welcome.

## Engineering principles

Changes should preserve:

- Spec-Driven Development for material features;
- Architecture Decision Records for durable architectural decisions;
- explicit security and tenant-isolation review;
- automated tests and CI evidence;
- deterministic, reviewable delivery;
- human approval for material product, architecture, security and merge decisions.

## Language policy

- identifiers and source-code APIs: English;
- technical documentation: Brazilian Portuguese by default;
- code comments and docstrings: Brazilian Portuguese;
- established technical terminology may remain in English.

See `docs/LANGUAGE_POLICY.md`.

## Security

Never submit credentials, tokens, private keys, personal data, customer data, private session URLs or sensitive logs.

See `SECURITY.md`.

## Pull requests

When external contributions are opened in the future, they must be based on a dedicated branch, remain narrowly scoped, pass all required CI gates and avoid unrelated formatting/refactoring.

The repository owner retains the final merge decision.
